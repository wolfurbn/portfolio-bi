UM POUCO SOBRE MIM

Tecnologia com contexto.
Dados com propósito.

Minha proposta é unir raciocínio analítico, conhecimento de processos e tecnologia para responder perguntas importantes para o negócio. Gosto de entender o problema antes de construir o indicador, com base em melhoria contínua, e de apresentar os resultados de forma clara para apoiar decisões.

No dia a dia, atuo entre clientes, Engenharia, Produção e área comercial, e já levo dados do SAP para dashboards em Power BI. Este portfólio reúne projetos demonstrativos, com dados fictícios, que mostram minha evolução em modelagem, Power Query e DAX.
